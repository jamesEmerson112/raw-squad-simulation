# Bug #001: Frozen middle

- **Status:** fixed
- **Filed:** 2026-05-22
- **Owner:** jamesEmerson112
- **Fixed:** 2026-05-24

## Symptom

When both armies advance to the middle of the map, every squad on both
sides halts simultaneously at ~max musket range and just trades shots.
Matches drag to a slow attrition stalemate instead of closing into a
decisive fight. Neither side reaches the capture point.

## Reproduction

- **Headless (preferred):**
  `.venv/bin/python tests/test_squad_freeze.py` — should pass and writes a
  centroid timeline for inspection.
- **Interactive:**
  `.venv/bin/python main.py` → setup screen → `capture_the_hill`,
  seed `1`, red 40 / blue 40, both `regular` profile, enter. Watch both
  lines stop ~200 px apart and stay there for ~40 sim-seconds.

## Root cause (confirmed)

`src/encapsulated_spark/sim.py:182–186`:

```python
if (
    unit.cover_waypoint is None
    and self._nearest_enemy_distance(unit, alive) <= ENGAGE_HOLD_DIST
    # ENGAGE_HOLD_DIST = DEFAULT_WEAPON.range_ * 0.85 = 187 px
):
    return  # halts unit; combat continues at max range
```

Every unit halts the instant a single enemy enters the 187-px ring.
With muskets at 220-px range, both sides freeze at near-max range where
hit chance works out to ~18% for regular discipline (see
`combat._hit_chance`). Combined with `reload_time = 2.5s`, that's
~0.072 hits per shooter per second — attrition crawls.

## Secondary cause

`src/encapsulated_spark/scenarios.py` `capture_the_hill` sets
`comp.objective = (cx, cy)` for **every** company on both teams, so all
squads pile onto the same x-coordinate and freeze on the same line.
There is no flanking or repositioning behaviour to break the deadlock.

## Fix applied

The fix replaced the global hard stop with local, discipline-weighted contact
behavior:

1. **Drop `ENGAGE_HOLD_DIST`** to `range_ × 0.52` (≈ 114 px) so units
   close to higher-accuracy range before halting. Likely the single
   biggest lever.
2. **Per-unit jitter** (±10–20 px) on the hold distance so the line
   ragged-ifies instead of every unit freezing at the same radius.
3. **Stagger squad objective offsets** around
   the cap point rather than stacking on its centre) so squads spread
   instead of stacking.
4. **Discipline-biased hold distance** (low discipline charges in;
   high discipline holds the optimal-range line) — interacts nicely
   with the existing discipline-driven AI.
5. Add squad-level contact reports and small contact-time repositioning so
   squads adjust under fire instead of parking in place.
